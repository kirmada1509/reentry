# ReEntry — Build With AI: Basics preparation

Factual technical notes, not invented personal reflection or a completed Devpost entry.

## Product and demonstration

ReEntry is a working local Chrome extension/web app for recovering interrupted work. The original manual demo captures selected instructions, saves user-confirmed progress, returns after a fictional instruction change, shows real AI interpretation with exact evidence, corrects/restores a checkpoint and opens the reviewed work link.

Public source: https://github.com/kirmada1509/reentry. Reproducible setup: README and docs/RELEASE.md. Add the actual public YouTube/Vimeo recording URL before submitting.

## Current product and demo

The automatic browser-agent iteration now proposes tasks, finish conditions, progress and next actions without a checkpoint form. The user controls site/model agreement and can inspect/correct its conclusions. Use the captioned application recording from the v0.2.0 technical preview; `docs/AGENT_RELEASE.md` explains reproduction, actual metrics and remaining native gates. The local app needs the documented model setup; no public hosted service is implied.

The new recording is supplied locally and through GitHub. A qualifying public YouTube/Vimeo URL is still a separate upload gate. The historical manual recovery demonstration remains available in v0.1.0.
