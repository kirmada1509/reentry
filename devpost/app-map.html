ReEntry: follow one recovery

This retrospective map covers the original manual capture flow. The later automatic agent observes chosen sites, infers tasks and records progress without a checkpoint form. Its current architecture, actual evaluation, recording instructions and open acceptance gates are documented in the agent architecture and the automatic release record.

A take-home guide to the actual product. This map is not evidence that a learner walkthrough occurred.

  1. Select and review instructions

    The WXT background worker reads an explicit selection. The capture preview shows the exact text and source. Browser form field values are outside the capture boundary.

    extension/entrypoints/background.ts → capture/page.tsx

  2. Save a confirmed checkpoint

    The browser validates a capture through native extension messaging. Dexie commits the task and first revision before the extension receives an acknowledgement.

    src/app/page.tsx → src/features/tasks/storage.ts

  3. Check what changed

    A source tab is bound to one task. The user recaptures the equivalent section. ReEntry keeps immutable before/current evidence and reports changed, unchanged or unverified captured material.

    src/app/check/page.tsx → src/features/sources/

  4. Ask the configured model

    The server prepares bounded context, calls NVIDIA or local Ollama, and validates evidence and confirmed progress. It has no browser tools or autonomous actions. Hosted processing requires fresh agreement.

    src/app/api/recovery/route.ts → src/features/recovery/harness.ts → src/lib/ai/

  5. Review, correct and continue

    The user reviews the proposed action. Its input digest must still match the task/source before saving or continuing. The app opens only the saved work link.

    src/app/recover/page.tsx → src/features/recovery/storage.ts

  6. Edit, restore or delete

    The checkpoint editor keeps drafts separate from confirmed facts. Saves use expected revisions, restore creates a new revision, and deletion uses minimal replay markers plus an extension-cleanup outbox.

    src/app/task/page.tsx → src/features/tasks/
